# 🏋️ Gym Management System

## 📌 About the Project

Gym Management System is a web-based application developed to manage gym activities efficiently. It helps gym owners manage members, visitors, membership packages, and other gym-related operations.

## ✨ Features

* Admin Login
* User Registration and Login
* Gym Member Management
* Visitor Management
* Membership Packages
* Cardiopackage
* Strength Package
* High Intensity Package
* User Dashboard
* Database Connectivity

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP

## 💻 Requirements

* XAMPP Server
* Web Browser
* Code Editor (VS Code)

## ⚙️ How to Run the Project

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Import the database SQL file using phpMyAdmin.
5. Configure database connection in `DBCONNECT.php`.
6. Open your browser.
7. Visit `http://localhost/GymWebsite/`

## 👩‍💻 Project Purpose

This project is developed to simplify gym management and make daily gym operations easier and more organized.
